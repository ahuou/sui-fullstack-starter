## Welcome to Sui fullstack

This folder is made to facilitate your sui coding experience. 

It is organised into three axis/folder: 

### Move 

This folder is your sui package. In here, you may deploy the move code that you will want to be interacted with in your frontend. From now on [this](https://move-book.com/) is your new bible.

### Frontend

This folder is your frontend, it is here that you will implement all the code of your website. It is already furnished with a few helpers that notably allow you to connect a user wallet and check its owned objects. It uses react ts to allow you to create a beautiful frontend. 

### Ts testing 

This folder is where you are encouraged to test your sui move call through typescript calls. It implements the [sui move sdk](https://github.com/MystenLabs/ts-sdks/tree/main/packages/typescript). We recommend you use it to simulate precise scenarios and verify the integrity of you code before directly implementing it in the frontend.
